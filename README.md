# Liquid Glass Weather Center — Android 16 (API 36)

Погодный центр нового поколения для **Android 16** в эстетике **Liquid Glass 3.0** с живыми погодными эффектами, графиками прогноза, поддержкой **120 Гц**, аппаратным **Motion Blur**, импортом **своих шрифтов (.ttf / .otf)** и **конструктором собственных тем** (можно собрать полностью чёрный, полностью белый, красный или любой другой стиль).

## Главные возможности

- **Реальная погода без API-ключей (Open-Meteo API)**:
  - Текущая температура, «ощущается как», влажность, ветер, давление, УФ-индекс, вероятность осадков, восход и закат.
  - Почасовой прогноз на 24 часа и подробный прогноз на 10 дней.
  - Поиск и сохранение любых городов мира на русском языке + офлайн-кэш.
- **Живые погодные эффекты**:
  - Анимированные частицы дождя, снега, солнечных лучей, облаков и молний, подстраивающиеся под текущую погоду (с возможностью включить демо-режим любой погоды для проверки эффектов).
- **Полный конструктор своего стиля (Theme Studio)**:
  - Быстрые базы: *Авто от погоды*, *Полностью чёрный (Pure Black)*, *Полностью белый (Pure White)*, *Красный неон (Crimson)*, *Liquid Ocean*, *Midnight Aurora*, *Material You*.
  - Ручная настройка **каждого цвета** через HSV-слайдеры (Оттенок / Насыщенность / Яркость) и палитры: фон, акцент, второй цвет призмы, оттенок стекла, цвет текста (авто-контраст или ручной).
  - Отключение флюидных сфер для идеально чистого чёрного/белого/красного фона.
  - Сохранение неограниченного числа собственных тем по имени.
- **120 Гц, Motion Blur и свои шрифты**:
  - Выбор герцовки экрана (**Авто / 60 / 90 / 120 / Макс. Гц**) + живой счётчик FPS.
  - Аппаратный **Motion Blur** (`RenderEffect`) при свайпах и нажатиях.
  - Импорт любых шрифтов **`.ttf` / `.otf`** с устройства.

## Сборка APK

### Через GitHub Actions (без Android Studio)
1. Загрузите содержимое архива в новый репозиторий на GitHub.
2. Перейдите во вкладку **Actions** → workflow **Android CI Build** автоматически соберёт `app-debug.apk`.
3. Скачайте готовый APK из раздела **Artifacts**.

### Через Android Studio
Откройте папку `LiquidGlassWeather` в Android Studio (Android SDK 36, JDK 17) и запустите на устройстве Android 12–16.
